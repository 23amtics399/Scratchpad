Scratchpad — Free Local-First Writing Workspace

A private, browser-based document workspace designed for focused writing, notes, and technical drafts. No accounts, no cloud dependencies, and complete privacy by default.

100% Local-First & Zero-Account Architecture

Scratchpad stores all notes, documents, folders, and workspace configurations entirely within your browser's IndexedDB storage via Dexie.js. Your writing never touches an external server, database, or analytics tracker. It loads instantly offline and continues to operate seamlessly without an internet connection.

Three Versatile Editing Modes

  • Rich Text Mode: WYSIWYG note taking powered by Tiptap and ProseMirror. Includes headings, checklists, code blocks with syntax highlighting, and desktop-grade table controls with custom borders.
  • Markdown Mode: Distraction-free Markdown writing with live syntax parsing and keyboard shortcuts powered by CodeMirror 6.
  • Plain Text & Code Mode: Fast, clean code editing with syntax highlighting for JavaScript, TypeScript, Python, HTML, CSS, SQL, JSON, Rust, and more.

Workspace Management & Data Portability

Organize documents with nested folders, search instantly across titles and document contents, and track revisions with automatic version snapshots. Export notes anytime to Markdown (.md), HTML (.html), plain text (.txt), or portable JSON backups.
